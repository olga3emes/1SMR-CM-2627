Se desea informatizar la gestión del Ministerio de Magia para controlar las misiones realizadas por los aurores en el mundo mágico.

De los aurores interesa almacenar su código de auror, nombre, fecha de nacimiento, rango, dirección y nivel de experiencia.

De las misiones se desea conocer el código de misión, nombre, descripción, nivel de peligro y fecha de inicio. Un auror puede participar en varias misiones, y una misión puede contar con varios aurores.

Las misiones se desarrollan en distintas localizaciones mágicas, de las que interesa guardar el código de localización, nombre, tipo de lugar (castillo, bosque, aldea, prisión, etc.) y región. Una misión se realiza en una única localización, mientras que una localización puede albergar muchas misiones.

Cada auror utiliza una o varias varitas mágicas, de las que interesa conocer el número de serie, material, núcleo mágico y longitud. Una varita solo puede pertenecer a un auror, pero un auror puede poseer varias varitas.

Además, durante las misiones pueden capturarse criaturas mágicas, de las que se desea almacenar el código de criatura, nombre, especie y nivel de peligrosidad. Una criatura puede aparecer en varias misiones y una misión puede involucrar varias criaturas.
