La organización de inteligencia WISE desea informatizar la gestión de las operaciones secretas realizadas por sus agentes.

De los agentes interesa almacenar su código de agente, nombre en clave, nombre real, fecha de nacimiento, especialidad y nivel de acceso.

Los agentes participan en distintas misiones, de las que se desea conocer el código de misión, nombre, objetivo, fecha de inicio, fecha de fin prevista y nivel de riesgo. Un agente puede participar en varias misiones y una misión puede requerir la participación de varios agentes. Además, para cada participación se desea registrar el rol desempeñado por el agente en la misión y la fecha en la que se incorporó.

Las misiones se desarrollan en una única ciudad, de la que interesa guardar el código de ciudad, nombre y país. Una ciudad puede albergar muchas misiones, pero cada misión se desarrolla únicamente en una ciudad.

Para realizar sus misiones, los agentes utilizan identidades falsas. De cada identidad interesa conocer el código de identidad, nombre utilizado, profesión ficticia y fecha de creación. Un agente puede utilizar varias identidades, pero cada identidad pertenece a un único agente.

Durante las misiones se vigila a diferentes objetivos, de los que interesa almacenar el código de objetivo, nombre, profesión, nivel de importancia y organización a la que pertenecen. Un objetivo puede ser investigado en varias misiones y una misión puede vigilar a varios objetivos. Para cada vigilancia se desea conocer el nivel de prioridad asignado.

Además, los agentes pueden utilizar distintos gadgets (micrófonos, cámaras ocultas, transmisores, etc.). De cada gadget interesa guardar el código de gadget, nombre, tipo y estado. Un gadget puede ser utilizado por varios agentes y un agente puede utilizar varios gadgets. Se desea registrar la fecha de asignación de cada gadget a un agente.
